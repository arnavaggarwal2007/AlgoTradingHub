# Logs Directory (`logs/`)

This directory contains the active runtime and audit log files generated by **Rajat Alpha v67 (Version 3.2)**.

---

## Active Log Files

| File | Type | Description |
| :--- | :--- | :--- |
| `rajat_alpha_v67.log` | **Application Runtime Log** | Captures all scanner activity, market bar fetching, technical indicators, pattern detections, entry/exit gating decisions, trailing stop adjustments, and order fills. |
| `audit.log` | **Institutional Compliance & Audit Log** | Immutable append-only audit trail logging every state mutation, stop modification, partial fill, API call, and critical system event with microsecond timestamps. |

---

## Log Analysis Tools

Do not manually scroll through large log files. Use the dedicated CLI and dashboard tools:

```bash
# Analyze last 7 days of logs (shows error counts, warnings, trade actions)
python tools/log_analyzer.py --days 7

# Analyze a specific date range and export to CSV
python tools/log_analyzer.py --start 2026-10-01 --end 2026-10-18 --csv docs/log_report.csv

# Launch the interactive web dashboard for real-time log inspection
python tools/log_dashboard.py
# Opens at http://localhost:5001
```

---

## Retention Policy
When log files exceed 100 MB, rotate the file by moving historical chunks to `backup/logs/`.
