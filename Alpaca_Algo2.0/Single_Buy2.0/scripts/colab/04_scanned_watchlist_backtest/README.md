# 🎯 Module 4: Scanned Watchlist Multi-Year Validation (`04_scanned_watchlist_backtest/`)

## Overview
Specialized backtest pipeline built to test **custom weekly candidate watchlists** generated by the screener against multi-year historical price action.

---

## 🎯 Features
1. Direct ingestion of `watchlist.txt` or candidate lists.
2. Evaluates historical trade frequency, pullback bounce rates, and symbol-by-symbol Sharpe ratios.
3. Classifies symbols into Suitability Tiers:
   - **Tier 1**: Elite high-expectancy swing tickers.
   - **Tier 2**: High-beta momentum tickers.
   - **Tier 3**: Range-bound or chop-prone tickers.
